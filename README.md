# STATUS

Интернет-магазин STATUS на Django: каталог с фотографиями, категориями,
ценами и остатками по размерам. Каталог управляется через админ-панель
Django Unfold.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте сайт на `http://127.0.0.1:8000/`, админ-панель — на
`http://127.0.0.1:8000/admin/`.

Добавляйте товары в админке: укажите цену в сомах, описание и фотографию,
затем добавьте остатки отдельно для каждого размера. Опубликованные товары
появятся в каталоге.

## Секретный ключ

Для постоянной работы и развёртывания задайте переменную окружения
`DJANGO_SECRET_KEY`. Если она не задана, локальный ключ генерируется
автоматически при запуске приложения.

## Развёртывание на Render

В настройках веб-сервиса Render укажите команду запуска `./start.sh`.
Перед запуском Gunicorn скрипт применит миграции, соберёт статические файлы
админки и создаст необходимые таблицы. WhiteNoise обслуживает CSS и JavaScript
Unfold в production.

В Render задайте переменные окружения для секретного ключа, режима отладки
и начальной учётной записи администратора:

В панели сервиса Render откройте **Environment** и добавьте `ADMIN_USERNAME`
(например, `admin`) и `ADMIN_PASSWORD` (длинный уникальный пароль). По
желанию добавьте `ADMIN_EMAIL` с действительным адресом. Введите пароль
непосредственно в Render, не публикуйте его в Git и не отправляйте в чат.

При запуске `start.sh` администратор создаётся после миграции базы. Если
такой администратор уже существует, его пароль и данные не изменяются.
Переменные окружения позволяют команде создать аккаунт снова, если база
данных бесплатного сервиса была сброшена.

Там же задайте `DJANGO_SECRET_KEY` (секретный ключ) и `DJANGO_DEBUG=False`.

Домен Render из `RENDER_EXTERNAL_HOSTNAME` добавляется в список разрешённых
автоматически. Локально можно продолжать использовать `python manage.py
runserver`.
